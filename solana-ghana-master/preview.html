The foundation

Validators

Run a six-week Validator School covering node setup, security, monitoring, incident response, and operations.

What members get
  • Hands-on access to a shared testnet/devnet validator
  • Path into the Solana Foundation Delegation Program (SFDP)
  • Validator-track resume line and referral network
Reference links Agave validator setup guide ↗ SFDP FAQ ↗ Validator Guidebook ↗

02

The rails

Stablecoin Sandbox

Experiment with issuance, settlement, Token-2022 transfer hooks, confidential transfers, and PYUSD / USDC flows.

What members get
  • Shared sandbox with test tokens, faucet access, and devnet infra
  • Mentorship from ChainPay / Token-2022 build experience
  • A credible demo project for grant applications
Reference links Token-2022 examples ↗ Confidential transfers skill ↗ Solana Foundation grants ↗
Join this team ↗
03

The frontier

Agentic Payments

Build on x402 and MCP tooling for agents that can pay each other, with human-approved and delegated-wallet modes.

What members get
  • Direct access to ChainPay architecture as a working reference
  • Up to $7 AI credit for experiments
  • Visibility for Colosseum and hackathon submissions
Reference links Solana x402 overview ↗ x402 getting started ↗ Network and token support ↗
Join this team ↗
